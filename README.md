# Zo gezegd 2.2 – Okuyucu

Statik web okuyucusu. GitHub Pages ile yayınlamak icin:

1. Bu klasoru bir repo'ya yukle.
2. Settings > Pages > Branch: main (root) sec.
3. Verilen adrese git; `index.html` otomatik acilir.

Klasor yapisi:

```
index.html
pages/   (kitap sayfa resimleri)
```
